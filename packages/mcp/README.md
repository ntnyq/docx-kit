# @docxkit/mcp

MCP (Model Context Protocol) server for docx-kit. Exposes tools for AI assistants to create, validate, and apply document templates.

## Installation

```bash
npm install @docxkit/mcp
```

## Usage

```ts
import { createDocxKitServer } from '@docxkit/mcp'

const server = createDocxKitServer()
// Connect to your MCP client
```
