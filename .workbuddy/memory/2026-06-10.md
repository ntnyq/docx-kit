## 添加 src/node 和 src/browser 平台目录 + 入口文件

### 新增目录/文件
```
src/
  node/
    fs.ts             # saveDocument() — Node.js 写磁盘（node:fs/promises）
    dataUrl.ts        # dataUrlToUint8Array() — Buffer 实现
    index.ts          # barrel re-export
  browser/
    dom.ts            # dataUrlToUint8Array() — atob 实现 + normalizeImageData() Blob 处理
    index.ts          # barrel re-export
  utils/
    dataUrl.ts        # 跨平台 auto-detect dataUrlToUint8Array（供 compiler/plugins 内部使用）
  node.ts             # 平台入口：导出 saveDocument, dataUrlToUint8Array，记录 ❌ echartsPlugin/normalizeImageData
  browser.ts          # 平台入口：导出 dataUrlToUint8Array, normalizeImageData，记录 ❌ saveDocument
```

### 重构
- `renderer/pack.ts` — `saveDocument` 改为 re-export from `../node/fs`
- `compiler/compileNode.ts` — 移除重复的 `dataUrlToUint8Array`，改用 `../utils/dataUrl`
- `plugins/qrcode/index.ts` — 同上，移除重复
- `plugins/echarts/index.ts` — 同上，移除重复
- `builder/DocxBuilder.ts` — `save()` 直接 import `../node/fs`
- `index.ts` — 新增 `dataUrlToUint8Array` 跨平台导出

### 配置更新
- `package.json` — 新增 `./node` 和 `./browser` sub-path exports
- `tsdown.config.ts` — entry 改为 `['src/index.ts', 'src/node.ts', 'src/browser.ts']`

### 不可用 API 标记
- **Node.js**: `echartsPlugin` ❌ (需 browser DOM), `normalizeImageData` ❌ (需 Blob)
- **Browser**: `saveDocument` ❌ (无文件系统)
- 使用 `declare const ... never` + `@deprecated` 文档化，autocomplete 可见但不允许使用
