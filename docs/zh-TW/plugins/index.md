# 外掛總覽

目前共有 **19 個內建外掛**，每個外掛都對應一個獨立 package 與一個獨立文件頁。

| 外掛 | 節點名 | 套件名 | 說明 |
| --- | --- | --- | --- |
| [Badge](./badge) | `badge` | `@docxkit/plugin-badge` | 狀態標籤 |
| [Barcode](./barcode) | `barcode` | `@docxkit/plugin-barcode` | 一維條碼 |
| [Callout](./callout) | `callout` | `@docxkit/plugin-callout` | 提示 / 警告區塊 |
| [Changelog](./changelog) | `changelog` | `@docxkit/plugin-changelog` | 版本變更表 |
| [Code Block](./code-block) | `codeBlock` | `@docxkit/plugin-code-block` | 程式碼區塊 |
| [Cover Page](./cover-page) | `coverPage` | `@docxkit/plugin-cover-page` | 封面 |
| [Data Table](./data-table) | `dataTable` | `@docxkit/plugin-data-table` | 資料表格 |
| [Divider](./divider) | `divider` | `@docxkit/plugin-divider` | 分隔線 |
| [ECharts](./echarts) | `echarts` | `@docxkit/plugin-echarts` | 圖表嵌入 |
| [Invoice](./invoice) | `invoice` | `@docxkit/plugin-invoice` | 發票模組 |
| [Letterhead](./letterhead) | `letterhead` | `@docxkit/plugin-letterhead` | 信頭 |
| [Meeting Minutes](./meeting-minutes) | `meetingMinutes` | `@docxkit/plugin-meeting-minutes` | 會議記錄 |
| [Page Number](./page-number) | `pageNumber` | `@docxkit/plugin-page-number` | 頁碼 |
| [Property Table](./property-table) | `propertyTable` | `@docxkit/plugin-property-table` | 屬性表 |
| [QR Code](./qrcode) | `qrcode` | `@docxkit/plugin-qrcode` | QR Code |
| [Signature Block](./signature-block) | `signatureBlock` | `@docxkit/plugin-signature-block` | 簽署區塊 |
| [Timeline](./timeline) | `timeline` | `@docxkit/plugin-timeline` | 時間線 |
| [TOC](./toc) | `toc` | `@docxkit/plugin-toc` | 目錄欄位 |
| [Watermark](./watermark) | `watermark` | `@docxkit/plugin-watermark` | 浮水印 |

## 額外依賴說明

- `codeBlock` 可選安裝 `highlight.js`
- `barcode` 需要 `bwip-js`
- `echarts` 需要 `echarts`
- `qrcode` 需要 `qrcode`
