# docx-kit brand assets

The mark combines a folded document, code brackets, and two content blocks:
documents built from code and composed through plugins.

| Asset | Use |
| --- | --- |
| `logo.svg` | Navigation, documentation home pages, and square placements |
| `logo-light.svg` | Horizontal signature on light backgrounds |
| `logo-dark.svg` | Horizontal signature on dark backgrounds |
| `../favicon.svg` | Simplified mark for browser tabs |

All assets are transparent SVGs. Wordmark lettering is outlined, so no font
installation or network request is required.

The palette is document teal (`#0F766E`), fold mint (`#5EEAD4`), ink
(`#173D3A`), and light lettering (`#ECFDF5`). The wordmark uses outlined
Avenir Next Demi Bold lettering.

Keep the original proportions and leave at least one eighth of the mark's
height clear around it. Use the full mark at 24 px or larger; use the favicon
for smaller placements. Use horizontal signatures at 160 px or larger.
