# 插件总览

当前共有 **18 个内置插件**，每个插件都对应一个独立 package 与一个独立文档页。

| 插件 | 节点名 | 包名 | 说明 |
| --- | --- | --- | --- |
| [Badge](./badge) | `badge` | `@docxkit/plugin-badge` | 状态标签 |
| [Callout](./callout) | `callout` | `@docxkit/plugin-callout` | 提示 / 警告块 |
| [Changelog](./changelog) | `changelog` | `@docxkit/plugin-changelog` | 版本变更表 |
| [Code Block](./code-block) | `codeBlock` | `@docxkit/plugin-code-block` | 代码块 |
| [Cover Page](./cover-page) | `coverPage` | `@docxkit/plugin-cover-page` | 封面 |
| [Data Table](./data-table) | `dataTable` | `@docxkit/plugin-data-table` | 数据表格 |
| [Divider](./divider) | `divider` | `@docxkit/plugin-divider` | 分隔线 |
| [ECharts](./echarts) | `echarts` | `@docxkit/plugin-echarts` | 图表嵌入 |
| [Invoice](./invoice) | `invoice` | `@docxkit/plugin-invoice` | 发票模块 |
| [Letterhead](./letterhead) | `letterhead` | `@docxkit/plugin-letterhead` | 信头 |
| [Meeting Minutes](./meeting-minutes) | `meetingMinutes` | `@docxkit/plugin-meeting-minutes` | 会议纪要 |
| [Page Number](./page-number) | `pageNumber` | `@docxkit/plugin-page-number` | 页码 |
| [Property Table](./property-table) | `propertyTable` | `@docxkit/plugin-property-table` | 属性表 |
| [QR Code](./qrcode) | `qrcode` | `@docxkit/plugin-qrcode` | 二维码 |
| [Signature Block](./signature-block) | `signatureBlock` | `@docxkit/plugin-signature-block` | 签署区块 |
| [Timeline](./timeline) | `timeline` | `@docxkit/plugin-timeline` | 时间线 |
| [TOC](./toc) | `toc` | `@docxkit/plugin-toc` | 目录字段 |
| [Watermark](./watermark) | `watermark` | `@docxkit/plugin-watermark` | 水印 |

## 额外依赖说明

- `codeBlock` 可选安装 `highlight.js`
- `echarts` 需要 `echarts`
- `qrcode` 需要 `qrcode`
