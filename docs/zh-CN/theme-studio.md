# Theme Studio

Theme Studio 使用英文界面，并已从代码 Playground 拆分为独立工具。

- Theme Studio：[/theme-studio](/theme-studio)
- 代码 Playground：[/playground](/playground)
- 主题指南：[/guide/themes](/guide/themes)

支持三种常用 Word 版式：商务报告、中文正式文档和学术长文。选择版式后可继续修改主题配色，并使用 Download Word 下载当前预览文件。

主题现在提供 Word 原生字体与标题样式；正文、表格及提示框共享主题色。预览保留导出的页边距，中英文字体可以分别设置。
